## Getting Started Playbook

Measure the connection first, then choose a bitrate with margin below it. Test during a pursuit in rain, because that scene uses more bits than a calm drive and it is the one that will fail first.

If motion blurs, either raise the bitrate within the margin or lower the resolution. Those are the two levers, and changing both at once makes the result impossible to interpret.
